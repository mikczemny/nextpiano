# Next Piano

Offline Android learning app for piano keys, scales and chords.

- No internet permission
- No accounts, ads or analytics
- Three learning modes: Keys, Scales, Chords
- Responsive piano keyboard for phones and tablets
- Light/dark mode and four color palettes
- Google Play target: Android 16 / API 36

Package name: `com.mikczemny.nextpiano`

The Android project is contained in the `app` module. Store listing and privacy-policy drafts are in `play/` and `docs/`.
